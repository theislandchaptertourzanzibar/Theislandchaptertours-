# The Island Chapter Tours

Welcome to The Island Chapter Tours website — a simple static site that showcases tours, excursions, and travel information for Zanzibar.

## About

This website presents the tour offerings, itineraries, prices, and contact information for The Island Chapter Tours. It's built as a static HTML site (Index.html) that can be viewed in any web browser.

## Features

- Landing page with overview and featured tours
- Individual tour details and itineraries
- Contact / booking information
- Mobile-friendly responsive layout (if supported by CSS)

## Getting started

To view the site locally:

1. Clone the repository:

   git clone https://github.com/theislandchaptertourzanzibar/Theislandchaptertours-.git
2. Open `Index.html` in your browser, or run a simple HTTP server from the project root:

   - Python 3:
     ```bash
     python3 -m http.server 8000
     # then open http://localhost:8000/Index.html
     ```

   - Node (http-server):
     ```bash
     npm install -g http-server
     http-server -c-1
     # then open http://localhost:8080/Index.html
     ```

## Editing the site

- The main page is `Index.html`. Update text, images, and links directly in that file.
- Place images in an `images/` (or similarly named) folder and reference them from the HTML.
- If you add CSS or JS files, keep them in `css/` or `js/` folders and update `Index.html` to load them.

## Deploying

You can host this repository as a static site using GitHub Pages:

1. Push your changes to the `main` branch.
2. In the repository Settings → Pages, set the source to the `main` branch (folder `/`), then save.
3. GitHub will provide a site URL (usually `https://<username>.github.io/<repo>/`).

Alternatively, host on Netlify, Vercel, or any static hosting provider by connecting the repository and following their deployment guide.
